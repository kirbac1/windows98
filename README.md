# Nostalgia 98

A Windows 98 desktop rebuilt in React and TypeScript. Real draggable
windows, a music player that synthesizes its own soundtrack, and the
games you used to open when you were supposed to be working.

Production: **https://windows98.kirbac.fi**

There are no image files in this project. Every bevel is a CSS
`box-shadow`, every icon is hand-drawn SVG, and every note you hear is
generated by an oscillator at runtime.

---

## What's in it

| | |
|---|---|
| **The shell** | Draggable, resizable windows with minimize/maximize/close, z-order focus, a taskbar with Quick Launch and Show Desktop, a Start menu with working submenus, a desktop right-click menu, and a shutdown screen with a boot sequence behind Restart. |
| **Display Properties** | Twelve wallpapers drawn as SVG tiles — Triangles, Waves, Bubbles, Blue Rivets, Straws, Circuits, Carved Stone, Houndstooth and the rest — plus a Screen Saver tab: Starfield Simulation, Flying Windows and Mystify Your Mind, on an idle timer you can set. |
| **Ctrl+Alt+Del** | The Close Program dialog, listing Explorer and Systray exactly as it always did. Ending Explorer does what ending Explorer used to do. |
| **Nostalgia Amp** | Three original chiptunes played by a lookahead step sequencer over the Web Audio API — square lead, triangle bass, filtered-noise drums. A real ten-band `BiquadFilter` equalizer, a spectrum analyzer reading an `AnalyserNode`, and an Open File button that plays your own audio through the same chain. |
| **Minesweeper** | Flood fill, three difficulties, right-click to flag, and a first click that can never be a mine. |
| **Solitaire** | Full Klondike with real drag-and-drop — pick a run up and carry it. Click-to-move still works if you prefer it, double-click sends a card home, and auto-finish clears the endgame. |
| **Paint** | Pencil, brush, eraser, line, rectangle, ellipse, and the 28-colour palette. |
| **Calculator** | Standard view, immediate execution, with memory keys, square root, percent and reciprocal. |
| **Nostalgia Explorer** | The web as it looked in 1998, including the error page you got the rest of the time. |
| **My Computer** | A navigable filesystem — `README.TXT` and `AUTOEXEC.BAT` open in Notepad. |

## Structure

- [`src/system/`](src/system/) — the desktop shell: window manager
  ([`Window.tsx`](src/system/Window.tsx)), menus, icons, geometry, and the
  [application registry](src/system/registry.ts).
- [`src/apps/`](src/apps/) — one file per application.
- [`src/audio/`](src/audio/) — [`tracks.ts`](src/audio/tracks.ts) is the
  music as step patterns; [`engine.ts`](src/audio/engine.ts) is the
  sequencer and the signal chain.
- [`src/game/`](src/game/) — Minesweeper and Solitaire rules, deliberately
  kept free of React so they can be tested directly.
- [`src/data/`](src/data/) — the C: drive, and the wallpapers
  ([`wallpapers.ts`](src/data/wallpapers.ts)), which are generated SVG
  tiles rather than bitmaps.
- [`src/styles/`](src/styles/) — `base.css` is the operating system,
  `apps.css` is the applications.


## Testing

```bash
npm run typecheck   # tsc --noEmit, strict
npm test            # Vitest
```

The suite covers the parts where a bug would be invisible until someone
hit it: that Minesweeper's first click is always safe (asserted over 200
generated boards), that Solitaire only allows legal stacks and that
auto-finish flips the card it exposes, that the track patterns are shaped
the way the sequencer indexes them, and a DOM smoke test that boots the
whole desktop and checks it comes up with its windows.

## CI/CD

[`.github/workflows/`](.github/workflows/) — `test.yml` (typecheck, unit
tests, production build) is called by `ci.yml` on every push and pull
request, and by `deploy.yml` before anything reaches the server. Pushing
to `main` builds `dist/`, ships it to a timestamped release directory,
publishes it into the document root, prunes old releases, and then
verifies the live site actually serves the desktop.

Setup, secrets, and rollback: [`DEPLOYMENT.md`](DEPLOYMENT.md).
